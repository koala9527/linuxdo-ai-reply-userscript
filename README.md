# Linux.do 有一说一 · 回帖与浏览辅助

Linux.do 油猴脚本：本地回帖候选文案、自动浏览话题和帖子、有限的页面状态观察。当前版本 **v1.3.1**。

> 不保证账号安全、不保证网站阅读计数增长。请遵守社区规则，不用自动化刷信任等级。Linux.do 禁止使用 AI 直接回复或润色回复；本项目不会自动填写或发送回复。

## 功能

- **回帖候选文案**：提取当前话题标题及已渲染楼层，调用本地「有一说一」服务生成文案，支持语气选择、重新生成、一键复制、输入预览、进度及错误提示。默认服务地址 `http://127.0.0.1:8011`。
- **自动浏览话题**：从最新、未读、新话题、热门列表或推荐话题中选择未浏览话题，保存本地历史；没有新话题就结束，不循环刷新。
- **自动浏览帖子**：逐楼滚动并停留，正文长度增加停留时间，支持换话题等待和阶段休息。
- **统一速度控制**：浏览面板提供 **0–100** 滑块，同时影响帖子滚动、停留、话题发现、跳转等待、冷却和阶段休息。
- **暂停与结束**：暂停期间不推进计数，恢复不重复启动同一任务；停止后不会再跳转或计数。
- **页面状态观察**：展示可见性、页面验证元素、部分遥测脚本迹象，以及能够观察到的 `/topics/timings` 请求状态。不是完整风控审计。

## 速度含义

| 速度 | 行为 |
|---|---|
| **0%** | 暂停；从速度暂停切换到非零值可以继续。手动暂停或安全暂停仍需手动恢复。 |
| 1% | 基础速度的 0.1 倍，等待时间 ×10。 |
| **10%（默认）** | **基础操作速度（1×）**，使用配置中的基础等待时间。 |
| 50% | 基础速度 **5 倍**，等待时间 ÷5。 |
| **100%** | 基础速度 **10 倍**，等待时间 ÷10。 |

计算方式：**操作倍率 = 速度值 ÷10；实际等待 = 基础等待 ×10 ÷速度值**。0% 单独处理为暂停。

例如基础帖子停留 10 秒，在 10% 下为 10 秒、50% 下为 2 秒、100% 下为 1 秒。长文额外停留也按相同比例调整。基础话题冷却 18 秒，在默认 10% 下为 18 秒、100% 下为 1.8 秒；每 5 个话题的基础休息 90 秒，在默认速度下为 90 秒、100% 下为 9 秒。

速度设置实时保存，刷新后保留；没有旧设置时默认 10%。正在进行的等待和滚动按新速度继续，不需要重新启动任务。0% 不会推进计数或自动点击。

等待使用异步定时器，滚动使用 `requestAnimationFrame`，不使用忙等或阻塞循环；速度变高不会增加同一时间的浏览任务数。等待时的面板刷新最多每 250 毫秒一次，暂停或速度变更在下一计时检查生效（最多约 250 毫秒）；不会修改浏览器的响应速度、焦点或输入事件。真实浏览器负载仍取决于页面和设备，不能保证任何情况下零卡顿。

**升级注意**：v1.3.0 的 10% 曾表示基础速度的十分之一；v1.3.1 已按上述含义修正。已保存的速度数值保持不变，任务实际速度会比旧版快十倍；原先设为 100% 的用户可先改回默认 10%。高速运行不保证账号安全，建议正常浏览使用默认速度。

默认本地上限：12 个话题、45 个帖子、每话题最多 6 楼。达到任一总上限即结束。**这些是本地操作统计，不是服务器确认的账号阅读统计。**

## 暂停规则与边界

- 任务需要手动启动，运行状态限于原标签页，不在其他已登录标签页自动复制。
- 页面隐藏、出现已识别的验证元素，或观察到计时请求 HTTP 403/429 时暂停；不会自动重试、处理验证或恢复安全暂停。
- 不伪造已读信标，不派发鼠标活动重置网站空闲检测，不修改可见性或浏览器指纹。
- 油猴隔离环境、页面实现及浏览器限制可能导致网络观察不完整；**未观察到限流或验证，不代表没有风控，更不代表不会封号**。
- 回帖结果按话题/页缓存 24 小时，最多 30 条；SPA 切换话题会刷新回帖状态。

## 安装和使用

1. Chrome 安装 Tampermonkey 或 Violentmonkey。
2. [安装或更新脚本](https://raw.githubusercontent.com/koala9527/linuxdo-ai-reply-userscript/main/linuxdo-ai-reply.user.js)。
3. 在已登录的 Linux.do 页面打开右下角面板，进入“浏览辅助”，调整速度和上限，然后点击开始。
4. 回帖功能需要单独启动本地 `reply-assistant` 服务；接口为 `POST /api/v1/say-one`，不直接调用模型接口。

## Chrome 调试控制器

`scripts/chrome-controller.mjs` 使用 **Node.js 22+** 原生 fetch/WebSocket，仅连接本机 `127.0.0.1:9222`，通过已安装脚本的面板控制任务，不注入另一套浏览引擎。

```bash
node scripts/chrome-controller.mjs --status
node scripts/chrome-controller.mjs --detect-risk
node scripts/chrome-controller.mjs --browse --speed=10
node scripts/chrome-controller.mjs --speed=50
node scripts/chrome-controller.mjs --speed=0
node scripts/chrome-controller.mjs --pause
node scripts/chrome-controller.mjs --stop
```

**仅登录普通 Chrome 不代表开启了 CDP。** 控制器不会关闭、重启或复制个人登录配置，也不会创建网站标签页。优先直接使用油猴面板。

如确需独立调试 Chrome，可以显式提供专用配置目录：

```powershell
node scripts/chrome-controller.mjs --start-chrome --profile=C:\Code\linuxdo-debug-profile
```

专用配置需要你手动登录并安装油猴脚本，不继承个人浏览器的 Cookie。不得使用个人 Chrome User Data 目录。
